Detailed Description

Client implementation for the Diffie-Hellman key exchange protocol.

This file contains the client-side implementation of the Diffie-Hellman key exchange protocol. The client communicates with the server to receive the prime number (p) and the generator (g), exchanges public keys, and computes a shared secret key.
