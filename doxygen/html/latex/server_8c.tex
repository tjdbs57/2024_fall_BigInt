\doxysubsection{Detailed Description}
Server implementation for the Diffie-\/\+Hellman key exchange protocol. 

This file contains the server-\/side implementation of the Diffie-\/\+Hellman key exchange protocol. The server communicates with a client to share the prime number (p) and the generator (g), exchanges public keys, and computes a shared secret key.
