Adds two big integers x and y, and stores the result in z. 

The function handles cases where one or both of the operands are zero, as well as when the signs of x and y are different. If the signs of x and y are different, it performs subtraction instead. If both have the same sign, it performs addition.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{ in}}  & {\em x} & Pointer to a pointer of the first bigint structure. \\
\hline
\mbox{\texttt{ in}}  & {\em y} & Pointer to a pointer of the second bigint structure. \\
\hline
\mbox{\texttt{ out}}  & {\em z} & Pointer to a pointer of the result bigint structure.\\
\hline
\end{DoxyParams}

\begin{DoxyItemize}
\item If x is zero, the function assigns y to z.
\item If y is zero, the function assigns x to z.
\item If x and y have opposite signs, the function subtracts the smaller magnitude from the larger one.
\item If x and y have the same sign, the function adds them and assigns the resulting sign to z. 
\end{DoxyItemize}

{\footnotesize\ttfamily void add\+\_\+core (\begin{DoxyParamCaption}\item[{\mbox{\hyperlink{config_8h_ac2bbd6d630a06a980d9a92ddb9a49928}{IN}} \mbox{\hyperlink{structbigint}{bigint}} $\ast$$\ast$}]{x,  }\item[{\mbox{\hyperlink{config_8h_ac2bbd6d630a06a980d9a92ddb9a49928}{IN}} \mbox{\hyperlink{structbigint}{bigint}} $\ast$$\ast$}]{y,  }\item[{\mbox{\hyperlink{config_8h_aec78e7a9e90a406a56f859ee456e8eae}{O\+UT}} \mbox{\hyperlink{structbigint}{bigint}} $\ast$$\ast$}]{z }\end{DoxyParamCaption})}



Adds two big integers and stores the result in a third bigint. 

This function takes two big integers represented as {\ttfamily bigint} structures, adds them together, and stores the resulting bigint in a third {\ttfamily bigint}. It ensures that both numbers have the same length by padding with zeros if necessary. The addition is performed in reverse order to handle carry appropriately.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{ in}}  & {\em x} & Pointer to the first bigint to add. \\
\hline
\mbox{\texttt{ in}}  & {\em y} & Pointer to the second bigint to add. \\
\hline
\mbox{\texttt{ out}}  & {\em z} & Pointer to the result bigint where the sum will be stored.\\
\hline
\end{DoxyParams}
This function performs the following steps\+:
\begin{DoxyItemize}
\item Determines the lengths of the input big integers.
\item Allocates memory for the result bigint based on the maximum length of the inputs.
\item Iteratively adds each corresponding word from the two input big integers, starting from the least significant word, while handling any carry from previous additions.
\item Stores the result in the appropriate position in the result bigint.
\item Handles any carry that may remain after the final addition.
\item Calls {\ttfamily bi\+\_\+refine} to remove any leading zeros from the result.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The input big integers should be properly initialized and should not be N\+U\+LL. The result bigint will be allocated and must be freed by the caller when no longer needed. 
\end{DoxyNote}
