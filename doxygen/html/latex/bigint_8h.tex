\doxysubsection{Detailed Description}
This file defines the data structures and macros for representing and manipulating big integers. 

It provides a flexible data type definition for large integers (big integers) using conditional compilation based on the word size (8, 32, or 64 bits). The {\ttfamily bigint} structure is used to represent big integers, which consist of a sign, the length of the number in words, and a pointer to the array holding the actual big integer value.

Key components\+:
\begin{DoxyItemize}
\item Conditional compilation to define the {\ttfamily word} type based on the word size.
\item The {\ttfamily bigint} structure to represent a big integer with a sign, word length, and the integer\textquotesingle{}s value.
\item Macros for calculating the maximum and minimum of two values.
\end{DoxyItemize}

The {\ttfamily bigint} structure allows for flexible handling of large integer arithmetic.
