Adds two words with carry handling.

This function performs addition on two words (A and B) and incorporates a carry from a previous addition. It checks for overflow and sets the carry_out accordingly.

Parameters
AThe first word to add.
BThe second word to add.
carry_inThe carry input from a previous addition.
carry_outPointer to store the carry output.
resultPointer to store the result of the addition.

This function performs the following steps:

  1. Adds the two input words A and B, storing the result in a temporary variable sum.
  2. Checks for overflow from the addition of A and B. If overflow occurs (i.e., if sum is less than A), sets carry_out to 1.
  3. Adds the carry-in (carry_in) to the sum from the previous step.
  4. Checks for overflow again after adding carry_in. If overflow occurs from adding carry_in (i.e., if sum is less than carry_in), increments carry_out by 1.
  5. Stores the final result of the addition (including the carry-in) into the provided result pointer (*result).

Adds two big integers and stores the result in a third bigint.

This function takes two big integers represented as bigint structures, adds them together, and stores the resulting bigint in a third bigint. It ensures that both numbers have the same length by padding with zeros if necessary. The addition is performed in reverse order to handle carry appropriately.

Parameters
xPointer to the first bigint to add.
yPointer to the second bigint to add.
zPointer to the result bigint where the sum will be stored.

This function performs the following steps:

  1. Determines the lengths of the input big integers (x and y).
  2. Allocates memory for the result bigint (z) based on the maximum length of the inputs, adding an extra word for carry.
  3. Iteratively adds each corresponding word from the two input big integers, starting from the least significant word, while handling any carry from previous additions.
  4. Stores the result in the appropriate position in the result bigint (z).
  5. Handles any carry that may remain after the final addition.
  6. Calls bi_refine to remove any leading zeros from the result.
