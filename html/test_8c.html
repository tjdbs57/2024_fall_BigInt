void print_bi_hex_py ( IN const bigint *  x)

Prints a bigint in hexadecimal format (Python-style).

This function prints the hexadecimal representation of the given bigint object. The format is similar to Python's hexadecimal literals, prefixed with "0x". If the number is negative, a "-" sign is prepended.

Parameters
[in]xA pointer to the bigint to be printed.
Precondition
x must point to a valid bigint object with an initialized array a and word length.
Postcondition
The hexadecimal representation of the bigint is printed to the standard output.
Note
This function handles different word lengths based on the WORD_BITLEN macro.
